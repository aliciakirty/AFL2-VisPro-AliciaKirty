# Bukti Pengujian Persistence

Langkah pengujian:
1. Menambahkan tiga tugas.
2. Menandai satu tugas selesai.
3. Melakukan Force Stop pada aplikasi.
4. Membuka kembali aplikasi.
5. Memastikan seluruh data tetap tersedia.

Hasil:
Data tugas dan status penyelesaian tetap tersimpan setelah aplikasi dibuka kembali.

Kesimpulan:
Pengujian persistence berhasil.
